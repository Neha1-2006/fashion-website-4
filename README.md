
# VogueStreet

A responsive streetwear and sneaker website built with HTML and CSS.

## Features
- Black-and-neon-green theme
- Streetwear categories
- Featured products
- About and contact sections
- Responsive layout

## Docker
Build: `docker build -t vogue-street .`

Run: `docker run -d --name vogue-street-container -p 8083:80 vogue-street`
